Contract financial engine — rules

Stated up front. 161 rules, numbered CON-R-001 … CON-R-161, each stated so a rule engine can consume it: trigger, inputs, computation or condition, output, confidence. Downstream modules (accounting, reporting, workflow) should cite these IDs rather than restating the logic.

Confidence labels

Per ../../CONVENTIONS.md:

LabelMeaning here
ObservedThe rule is literally stated by a field name, a UI label, or a declared type in _lucernex_objects_summary.txt / docs/data-fields/. Includes formulas Lx encoded in its own labels (e.g. Sub Total #1 (C+NC-D)).
DerivedComputed or deduced from Observed data — counting, cross-referencing two sources, or a reading with no plausible alternative.
InferredDomain reasoning, naming convention, or analogy. Not confirmed. Anything Inferred that touches money must be verified before it becomes code.

No rule below was verified against a running Lx instance. Every Inferred rule that affects a monetary result appears in the owning document's ## Open questions.
