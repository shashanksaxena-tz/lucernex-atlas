Lx, as it actually runs

Vendor-hosted IWMS · (ASG) American Freight · build 26.08.0.46 (2026/08/26 16:15) · captured 2026-09-10

Lx is the lease-accounting and contract-management system this programme is rebuilding. It stores a property or equipment lease as a contract — 570 fields across 4 physical tables — and hangs everything else off it: the rent schedules an accountant signs off, the CAM reconciliation a tenant audits, the approval workflows a request passes through, and the page layouts an administrator assembles all of it from. Almost the entire application is rendered from a layout registry rather than written screen by screen, which is why configuration matters here more than code.

Everything on this site was read out of the running application and its own schema tools — nothing is from a manual. Every claim carries an evidence label: Observed means somebody saw it, Derived means it follows from something observed, Inferred means nobody has confirmed it yet. Where a fact is missing it is written down as missing, which is what the 528 open questions are.
