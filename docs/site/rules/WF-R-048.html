WF-R-048

Workflow & Approvals · D. Step execution and dates

Derived

Only the same user or a system administrator can release the lock. This is a directly reported defect: "People check out by mistake all the time… I have to manually navigate to each item and check it in." ASG's own proposed fix is recorded verbatim: rename to Lock/Unlock, grant managers the unlock right, and expire after 48 hours (D9).
