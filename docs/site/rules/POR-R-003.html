POR-R-003

Portfolio & Real-Estate Transactions ·

Observed
A user opens a `Facility`/`Location`/`Parcel`/`Prototype`/`Contract`/`CapProject`/`OpenProject`/`EquipmentContract` detail screen under a given Portfolio
`Program.<Subtype>SetupPageLayoutID`
Overrides the tenant-wide default from `Firm.<Subtype>SetupPageLayoutID` for that Portfolio. Two additional fields, `SiteToProjectSetupLayoutID` and `ProjectToFacilitySetupLayoutID`, exist only on `Program` and name a conversion between subtypes rather than one subtype's own layout — see `POR-R-012`.
Observed field existence; Inferred override semantics
