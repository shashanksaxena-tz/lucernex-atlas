CON-R-033

Contracts & Leases · 3. Recurring expense: setup and schedule

Observed

The clause is flagged IsCustomPaymentCoverage: the same ExpenseSetup record supports annual, quarterly or semi-annual coverage without a schema change, via explicit month-and-day markers per frequency.

`ExpenseSetup.IsCustomPaymentCoverage = true`
`CoverageBeginAnnual`, `CoverageBeginQ1..Q4`, `CoverageBeginSemiAnnual1..2`, `PaymentDueAnnual`, `PaymentDueQ1..Q4`, `PaymentDueSemiAnnual1..2`
