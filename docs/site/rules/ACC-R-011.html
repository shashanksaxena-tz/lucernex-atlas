ACC-R-011

Lease Accounting & Payments · ⚠ Final classification (inverted polarity)

Observed

Any fail means finance; all five passes means operating.

- Trigger: after ACC-R-005…010. - Inputs: `Test1Result` … `Test5Result`. - Condition: any result = Fail ⇒ `Finance`; all five = Pass ⇒ `Operating`. - Output: `ContractFinancialTest.FinalResult` (`sTYPE_TEXT`); `CodeAccountingMethodID` set to the matching Accounting Method code. - Confidence: Observed, stated on all five test fields. ⚠ Note the polarity is the reverse of the intuitive reading — "passing" the tests means the lease is *operating*.
