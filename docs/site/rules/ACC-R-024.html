ACC-R-024

Lease Accounting & Payments · Recalculation override

Derived

A note is recorded against the schedule. Whether it clears Recalc? is undocumented.

- Trigger: a user declines to recalculate a dirty schedule. - Inputs: free text. - Output: a `RecalcOverrideNotes` row linked by `SLSummaryID`; the id appended to `SLSummary.RecalcOverrideNotesIDList`. - Confidence: Derived — the object exists and is described as *"A free-text note explaining why a financial recalculation was manually overridden — an audit-style justification field"* (`docs/data-fields/INDEX.md`), but the workflow that creates it is not documented. Whether creating a note clears `NeedsRecalculation` is unknown. --- ## D. Schedule generation
