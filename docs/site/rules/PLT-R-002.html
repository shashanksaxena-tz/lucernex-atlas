PLT-R-002

Platform & Tenancy · `FirmID` is not a first-class reference type

Derived

- Trigger: Any code generator or ORM that maps Lucernex's declared `<Entity> ID` FK types to foreign keys. - Input: The type vocabulary (`Facility ID`, `Contract ID`, `Employer ID`, …, and `FirmID` itself, typed `Text`). - Condition: No `Firm ID` type exists among the declared FK types. - Effect: A schema-driven FK inference tool will silently miss the one relationship every row in the product ultimately has. Tenant references must be modelled deliberately, not discovered. - Confidence: Derived — `project-entity.md` §4, corroborated by the type list in `../../data-model/graphql-api.md`.
