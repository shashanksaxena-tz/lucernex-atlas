LAY-R-164

Configuration, Layouts, Forms & Reporting · F. Forms

Observed
A form instance is an `Issue` record. `Issue.LastPageLayoutID` records *"the name of the last form layout used to update the issue"* — singular, so it is depth-1 history, not a per-step audit trail. It does not make a multi-step form reproducible as each participant saw it.
