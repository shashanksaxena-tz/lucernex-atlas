ACC-R-015

Lease Accounting & Payments · Auto-computation marker

Observed

Set when the system ran the test rather than a user. The trigger is unknown.

- Trigger: the system runs the test without user entry. - Output: `ContractFinancialTest.AutoComputed := true`. - Confidence: Observed — *"This field will have a true value if the ASC 842 test was computed automatically by the system."* The conditions under which the system auto-runs are not documented.
