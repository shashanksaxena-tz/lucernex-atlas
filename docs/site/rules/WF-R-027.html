WF-R-027

Workflow & Approvals · C. Routing resolution

Derived

User Class routing resolves against Member.CodeUserClassID intersected with the entity roster; Org Chart Level routing walks Member.SupervisorID the configured number of hops from an anchor that is itself unstated (OQ-22); assignees and notifiees are resolved through the identical pipeline used for approvers, just against their own type/list columns.

Step instantiation
`WFTS.ApproverType` = User Class; `ApproverUserClassIDList`; `Member.CodeUserClassID`
—
`WFS.ApproverMemberIDList` = every member on the entity in one of the listed classes
