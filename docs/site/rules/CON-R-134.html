CON-R-134

Contracts & Leases · 11. Typing and integrity rules for the rebuild (Constitution §4.4)

Observed

Migrating any parent-child edge: seven FKs are declared Text rather than typed, though the target's proper FK type exists elsewhere in the same schema; model them as real FKs with an orphan-handling policy.

Migrating any parent-child edge
Seven `Text`-typed FKs (`PaymentTransaction.ExpenseRecoveryID`, `.ScheduledOffsetID`, `ExpenseSchedule.Previous/NextExpenseScheduleID`, `ExpenseAccrualSchedule.ExpenseAccrualSetupID`, `AccrualTransaction.ExpenseAccrualSetupID`, `ExpenseRecoveryItem.ExpenseRecoveryID`, `LandlordInvoiceItem.LandlordInvoiceID`, `LinkLandlordInvPaymentTxn.LandlordInvoiceItemID`)
Declared `Text` rather than a typed FK, though the target's FK type exists elsewhere
