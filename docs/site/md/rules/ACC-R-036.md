# ACC-R-036 — Remaining cash balance

*Lease Accounting & Payments · Observed*

**`CurrentRemainingCashBalance` = sum of current and future remaining lease payments; `CurrentRemainingCashBalanceAfterReportEnd` = the same excluding the current period.**

One figure includes the current period, the other excludes it.
