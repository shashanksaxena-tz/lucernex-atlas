Vendor definition: "When added to a form, this field allows users with appropriate permissions to reassign approvers by job title." Reassignment is a form field an administrator places on a layout, not a workflow operation, and it can only redirect to a job title, never to a named person. Whether it persists back to the template or only to the running step is unresolved (OQ-26).
