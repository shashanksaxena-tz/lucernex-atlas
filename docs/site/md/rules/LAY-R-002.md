# LAY-R-002 — The reconciliation, stated as rules

*Configuration, Layouts, Forms & Reporting · Derived*

**A Page Layout presents a platform-defined entity. It does not define fields;.**

A Page Layout presents a platform-defined entity. It does not define fields; it arranges fields drawn from that entity's Data Fields catalog.
