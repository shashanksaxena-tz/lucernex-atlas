# ACC-R-046 — Mid-period remeasurement split

*Lease Accounting & Payments · Observed*

**`InterestBeforeMidRemeasure` = partial interest from period start to the remeasurement date; `SleBeforeMidRemeasure` = partial single lease expense over the same span.**

Two fields hold the partial interest and partial expense from the period start to the remeasurement date.

## Stated for a rule engine

|  |  |
|---|---|
| When it fires | remeasurement effective mid-period |
| What it writes | `InterestBeforeMidRemeasure` = partial interest from period start to the remeasurement date; `SleBeforeMidRemeasure` = partial single lease expense over the same span |
