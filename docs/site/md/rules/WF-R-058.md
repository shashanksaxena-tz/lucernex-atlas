# WF-R-058 — E. Approval decisions

*Workflow & Approvals · Observed*

**MoveToStepNumber is a plain integer the administrator types in. A lower number is a send-back;.**

MoveToStepNumber is a plain integer the administrator types in. A lower number is a send-back; nothing in the schema distinguishes it from ordinary forward movement, so no report can tell rework loops apart from progress.
