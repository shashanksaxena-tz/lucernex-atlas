# WF-R-038 — D. Step execution and dates

*Workflow & Approvals · Observed*

**DueDateApprovers = StartDate + DurationDaysApprovers; DueDateAssignees is computed the same way for the assignee clock;.**

DueDateApprovers = StartDate + DurationDaysApprovers; DueDateAssignees is computed the same way for the assignee clock; DueDate is whichever of the two governs the step overall.
