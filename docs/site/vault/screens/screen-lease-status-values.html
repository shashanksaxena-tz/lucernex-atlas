This screen answers a question that was open for most of this corpus's life. The platform's Contract Status Code has three values and never matched BRD-24 — it does not have to, because ASG tracks the lifecycle in a field it defined itself.

And it opens a new one: finding-lifecycle-has-no-ordering. A rebuild that models an ordered state machine is making a decision, not migrating one — q-bbw-20-lease-status.

Note the name collision: a platform Lease Status Code (2043) also exists, with exactly one value (Expired). Different thing, same name. See client-drop-down.
