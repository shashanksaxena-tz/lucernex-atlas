What to know before rebuilding this

Firm-global reference data Derived

Owned by the firm as a whole rather than by any one business record — configuration and reference data rather than transactional rows.

No typed relationships either way Derived

Nothing holds a typed foreign key into this record and it declares none out. Either it is joined by a soft reference the census cannot see, or it is genuinely standalone — worth settling before anything is built on it.
