**`DOC-R-008`** · [[module-documents-folders]] · **Observed**

A folder template declares which entity types it applies to through **eleven `IsValidFor*` flags** —
**the same matrix as [[CodeIssueType|Forms]]**.

One pattern, three places: forms, folder templates, and the `VirtualTemplate*` projections.
