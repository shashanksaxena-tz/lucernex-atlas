**`RPT-R-010`** · [[module-reporting]] · **Observed**

Report columns draw from the **same [[data-field-catalog|field registry]]** as forms —
[[ReportGroupAvailableField]]. **There is no separate report-field catalog.**

The vendor says so in its own schema: the FK type is literally named **`Report/Form Field ID`**.

See [[rules-reporting]] for the full register.
