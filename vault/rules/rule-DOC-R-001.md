**`DOC-R-001`** · [[module-documents-folders]] · **Observed**

A save is **blocked** without `ParentFolderID`. Contrast [[rule-DOC-R-004]] — the [[Folder]] tree has
genuine roots; [[Document]] never does.

See [[rules-documents-folders]] for the full register.
