**`LAY-R-101`** · [[module-layouts-and-forms]] · **Observed**

Summary Pages, Sub-pages, List Layouts, Forms, Wizards, Map Popups, Reports and Dashboard tiles are
**all [[PageLayout]] rows**.

One record type, discriminated by booleans. This is the single most useful fact about the product's
architecture — see [[page-layout-concept]] — and it is why
[[q-bbw-23-1647-layouts|1,647 rows exist against 135 registered layouts]].

See [[rules-layouts-and-forms]] for the full register.
